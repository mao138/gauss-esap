Interpretación matemática del sistema

Carga una matriz para que la herramienta identifique automáticamente si el sistema tiene solución única, infinitas soluciones o ninguna solución, y para que señale las variables libres cuando corresponda.

La exportación a PDF se habilita únicamente cuando el procedimiento alcanza una forma final que permite la interpretación del sistema.

1. Ingresar matriz

Escribe la matriz aumentada usando comas para separar columnas y saltos de línea para separar filas. Se admiten enteros, decimales con punto y fracciones.

Formato esperado: una fila por línea y columnas separadas por comas. Ejemplo: 2,1,-1,8
